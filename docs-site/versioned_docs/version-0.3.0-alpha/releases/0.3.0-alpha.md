# ReelBolt 0.3.0-alpha

**Released** 10 November 2026 · **tag** `v0.3.0-alpha`

This is the third alpha release. It is still an **alpha**: early access, no service-level guarantee, and
features may change. This page records what you can do now that you could not do in
[0.2.0-alpha](./0.2.0-alpha.md). Security fixes are included in this release.

## What is in it

- **ReelBolt in Italian.** Choose Italian as your language and the dashboard, the website, the e-mails
  ReelBolt sends you and the user guide all appear in Italian. This covers projects, files, apps, runs,
  the editors, the assistant, workspace settings, billing and credits, sign-in and account screens. Your
  language choice is saved with your account. A page that is not translated yet appears in English.
- **A guided start.** A first-run tour and a **Getting started** checklist in the dashboard walk you
  through your first video, and they point to [The basics](../basics/index.md): ten short illustrated
  guides from sign-up to your first video. If you upload videos to a new project, ReelBolt now offers to
  create a footage edit for them.
- **Ask for several changes at once.** In [Request changes](../workflows/request-changes.md) you can
  describe several changes in one request and review them together in one panel. The assistant can
  propose and apply several changes in one go as well.
- **Cut out and mask objects in the editor.** In [the timeline editor](../editor/index.md) you can mark
  an object on a clip, have ReelBolt track it, and apply a mask to it. The final film shows the mask
  exactly; the preview in the editor is an approximation.
- **A more accurate preview.** The editor preview now shows blur, pixelate, mono and vignette effects
  while you work, drawn the way the final film will draw them. Previews of portrait phone video are
  sharper. If your browser cannot show the preview, the editor says so and gives you a way back.
- **An editor that follows professional habits.** Editor pages have their own addresses, so reload and
  the back button keep you where you were. Tools are easier to find, and a command palette and a
  searchable shortcut list are available. The editor is still an **Early preview**.
- **A better editor on a phone.** Play stays on screen, the picture fits, buttons are bigger to touch,
  and the phone can no longer get stuck in full view.
- **The editor list shows one row per run.** The list of timelines now shows the final film of each run.
  Intermediate steps are available when you ask for them.
- **Organise your projects.** [Organising projects](../projects/organizing-projects.md) covers tags and
  folders, and [Activity by tag](../projects/activity-by-tag.md) shows the runs and credits each tag used.
- **More tools in the editor.** [Fix colour and exposure](../editor/fix-colour-and-exposure.md) adds colour
  wheels and a one-click exposure fix, [Camera profiles](../editor/camera-profiles.md) handles footage
  shot in a log profile, and [Clean your audio](../editor/clean-your-audio.md) removes hum, wind, hiss and
  echo, or isolates a voice. [Background activity](../editor/background-activity.md) shows what is still
  working while you edit.
- **Show a picture or a clip over your film.** [Picture over video](../recipes/picture-over-video.md)
  shows a screenshot, review, logo or clip over the film, full screen or in a corner.
  [Blur or mask an object](../editor/blur-or-mask-an-object.md) and
  [Blur or highlight one object](../recipes/prompted-region-effects.md) apply an effect to just one object.
- **Better narration.** ReelBolt now judges whether a narration fits the film by measuring the speech,
  with a hard limit on speaking speed. It also no longer plays a second voiceover over a film that is
  already narrated.
- **A green screen app that does what it says.** The app that puts your content on a green screen now asks
  what should appear there. If nothing is given, the run fails with a clear message instead of returning
  your video unchanged.
- **Clearer messages.** When a run fails because of your input, the run page shows the message from the
  step that failed. The readiness check on the run page speaks your language. A missing source file is
  reported in plain words.
- **Rotated phone videos work as expected.** ReelBolt reads the true size of videos that your phone
  recorded rotated, and straightens them before it finds objects in them. Landscape clips no longer
  default to a vertical shape.
- **A calmer run form.** The new-run form is simpler, and ReelBolt asks you to confirm before a run that
  costs a lot of credits.
- **Clearer billing.** The plan and billing pages are easier to read, and the checkout return confirms
  your purchase.
- **A new look for controls.** Sliders and switches have a new blade shape, and ReelBolt uses its own
  pointer set across the app and the website.
- **The documentation is easy to find.** The website's menu and footer and the dashboard's **Help** and
  account menus now link to this guide, in your language. The workspace menu is now called **Workspace**
  (it was **Organization**), and a project's tabs include **Apps**.
- **Smaller fixes.** The assistant is docked on desktop and its phone sheet is full height and easy to
  read. The workspace menu on a phone no longer gets stuck. The YouTube thumbnail preset works, and
  the resend button in the unverified e-mail banner works.

## Operators and reliability

- **Security hardening.** This release includes security fixes.
- **Clearer limits for generated video code.** Instructions and refusals now describe what generated code
  cannot do offline.
- **Animation in video templates.** Generated video code can use one more animation library, driven by the
  video frame.
- **Updated framework.** The dashboard and the website run on a newer version of Next.js.
- **Better warnings before a run.** The checks that run before a run warn when a label chosen for censoring
  matches only a kind of track it cannot act on.

## What is not in it

- **The timeline editor is not final.** It is still an **Early preview** and is labelled as one on every
  editor page. Expect tools to change.
- **Italian is not complete everywhere.** A few pieces of text still appear in English, and a page that
  is not translated yet is shown in English.

## Where it runs

ReelBolt 0.3.0-alpha runs on the hosted service at reelbolt.ai.

## Upgrade notes

There is nothing to migrate. If you are new, start with [The basics](../basics/index.md). To read the
guide as it was for earlier alpha releases, choose **0.2.0-alpha** or **0.1.0-alpha** in the version
menu in the documentation header.
