# Pair the Runner

Pairing starts on your computer and is finished in ReelBolt.

1. Start the Runner. On Windows, open **ReelBolt Runner** from the Start menu. On Linux, start the app or run `reelbolt-runner pair`.
2. The Runner shows a short code of eight characters, like `7HQD-4M2R`, and opens a ReelBolt page in your browser. If no browser opens, open the address the Runner prints.
3. Sign in to ReelBolt if asked. On the **Pair a runner** page, check that the code matches the one on your computer, character for character.
4. Choose the workspace to pair the computer into. You can pick your Personal workspace or any workspace where you are an Owner or Admin.
5. Click **Approve this device**. Click **Deny** if you did not start this.
6. Go back to the Runner. It shows that it is paired. The computer now appears in the workspace under **Runners**.

The code is short-lived. If it expires, ask the Runner for a new one. Every Owner of the workspace gets an email when a device is approved.

How the workspace decides when to use your computer, and how to remove it, is on the [Desktop runner](../account/desktop-runner.md) page.
