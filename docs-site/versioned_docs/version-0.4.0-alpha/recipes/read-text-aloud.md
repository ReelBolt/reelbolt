# Read your text aloud

**Goal:** get an audio file of a voice reading your text.

## Recipe: Read my text aloud

**Inputs.** **Text to read**, a **Voice** and a **Language**. Under **More options** you can pick the voice model. You need a voice provider in your workspace. The text is spoken as written: it is not translated or rewritten.

**What it costs.** It uses credits and a voice. The price shows on the run page before you start.

**What you get.** One audio file in the project.

**If it fails.**

- The run stops asking for a voice: add a voice provider to your workspace.
- A long paragraph is refused: split it into shorter paragraphs.
- The reading is in the wrong language: set **Language** to the language of the text. For a translation, write the translated text yourself.

**Permission to send media.** Only your text goes to the voice provider. No pictures or videos are sent.
