# Make music or a sound effect

**Goal:** get an audio file of music or of one sound, from a description.

## Recipe: Music or sound effect

**Inputs.** Choose **What to make**: **Music** or **Sound effect**. Then describe it (**Describe the music** or **Describe the sound**; only the one that applies is shown). Set the length: 15 to 120 seconds for music, 1 to 8 for a sound. **Takes** (1 to 4) is how many versions you get. Under **More options** you can pick the music or sound effect model. You need a music or sound-effects provider in your workspace.

**What it costs.** It uses credits, and every take is charged, so four takes cost more than one. The step has a spend cap. The price shows on the run page before you start.

**What you get.** Each take saved as an audio file in the project.

**If it fails.**

- The run stops asking for a provider: add a music or sound-effects provider to your workspace.
- You asked for a sound longer than 8 seconds: for a longer track, choose **Music**.
- The result is not what you described: add detail (instrument, speed, mood) and run again, with one take first.

**Permission to send media.** This recipe sends only your description. It does not send your files, and no media permission is involved.
