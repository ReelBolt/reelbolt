# Effects on a clip

**Goal:** apply one effect to a clip without changing anything else. The result is a new MP4.

This app replaces the older "blur one object" and "green screen insert" recipes. Their old names still open it
with the matching choice set.

## Before you run it

- **Your clip** uploaded to the project.
- For **Put content on a screen**: the picture or video that goes on the screen.
- Finding an object sends the clip to a tracking service. That permission is off, and you give it in the app on
  the first step. It is never a field of this app, so a run stops before anything leaves the server until you allow it.

## The fields

| Field | What it does |
|---|---|
| **What to do** | Blur an object, put content on a screen, or follow a subject. |
| **What to hide** and **How to hide it** | Blur only: name the object in plain words, then blur or pixelate it. |
| **What to follow** | Follow only: name the subject; the camera keeps it in frame. |
| **What goes on the screen** | Screen only: the picture or video to show. |

## What you pay for

Blur and follow use credits for tracking the object. Putting content on a screen uses processing time only.
