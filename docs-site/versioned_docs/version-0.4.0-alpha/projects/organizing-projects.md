# Organizing projects with tags and folders

When a workspace grows past a handful of projects, folders and tags keep them easy to find. Both belong to the workspace, so everyone in it sees the same ones.

## Folders and tags: which to use

- A **folder** is a place. A project sits in one folder or in none. Folders do not nest: there is one level.
- A **tag** is a label. A project can carry up to 20 tags, for example a client name and a season. Tag names are 1 to 40 characters, and two tags cannot share a name, whatever the capitals. A workspace can hold up to 200 tags and 500 folders.

Tags are the lighter way to separate clients. If you only need to tell client work apart, tag each project with the client's name. You do not need a workspace per client (see [Workspaces and teams](../workspaces.md)). Tags also feed [Activity by tag](./activity-by-tag.md).

## Find projects

The projects page has a list on the side with your folders (and **No folder**) and your tags. Click a folder to see only its projects. Click one or more tags to narrow the list; with several tags selected you see only projects that have all of them. **Clear tags** resets the tag choice. Each card shows its tags and, when you are looking across folders, its folder.

## Manage folders and tags

Click **Manage folders and tags** to open a dialog with a **Tags** tab and a **Folders** tab. Type a name and add it. You can rename either kind, and give a tag one of ten colours: gray, red, orange, yellow, green, teal, blue, indigo, violet or pink. The colour never carries meaning alone, because the tag name is always shown beside it.

Deleting a tag removes it from its projects and nothing else. Deleting a folder keeps its projects and moves them to **No folder**. The dialog tells you how many projects are affected before you confirm.

Creating, renaming, recolouring and deleting tags and folders needs permission to edit in the workspace. Viewers can use the filters but cannot change anything.

## Tag or move one project

Open the menu on a project card:

- **Tags...** opens a box where you search for a tag or create one by typing its name.
- **Move to folder...** lets you pick a folder, or **No folder** to take the project out of its folder.

The menu is always there, so it is also the way to organize with the keyboard or on a phone. You can also set a folder and tags when you create a project.

## Drag a project onto a folder

On a computer, drag a card onto a folder in the side list. A message confirms where it went. Dragging is a shortcut only: everything it does you can do from the card menu.

## Change many projects at once

1. Click **Select projects**.
2. Tick the projects, up to 100 at a time.
3. Choose **Add tag**, **Remove tag**, **Move to folder** or **Clear folder**, pick the tag or folder, and click **Apply**.
4. Click **Done selecting**.

A bulk change is all or nothing: if it cannot be applied to every selected project (for example, one would go over 20 tags), none changes.

## Ask the assistant

The assistant can tag and file projects for you. Say "put the Acme projects in a folder called Acme and tag them acme". It uses names, creates missing tags and folders, and shows you what it will do (including "will create tag Acme") before you approve. See [the assistant](../assistant/index.md).
