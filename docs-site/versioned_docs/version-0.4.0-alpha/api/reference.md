# API reference

The full list of routes, parameters and answers is published as an OpenAPI 3 document on your ReelBolt
address:

```text
https://<your ReelBolt address>/api/public/v1/openapi.json
```

It needs no key. Import it into a tool such as Postman or Insomnia, or use it to generate a client in your
language. It is available when the API is turned on for your installation.

For how to use it, start with the [quick start](./index.md), then read [Keys](./keys.md) and
[Errors](./errors.md).
