# ReelBolt 0.3.1-alpha

**Released** 10 November 2026 · **tag** `v0.3.1-alpha`

This is a point release after [0.3.0-alpha](./0.3.0-alpha.md). It is still an **alpha**: early access, no
service-level guarantee, and features may change. This page records what you can do now that you could not
do in 0.3.0-alpha.

## What is in it

- **The ReelBolt API.** You can now start runs and collect their results from your own code. [The ReelBolt
  API](../api/index.md) says what it is for and which plans include it, and walks through a first call:
  create a key, start a run from a template, receive a webhook and fetch the output link. See also
  [API keys](../api/keys.md), [Runs](../api/runs.md), [Webhooks](../api/webhooks.md),
  [Limits and credits](../api/limits-and-credits.md), [Errors](../api/errors.md) and the
  [Reference](../api/reference.md).
- **Better footage edits.** When ReelBolt cuts your footage, cuts no longer fall inside a spoken word. The
  editing step now sees an outline of the whole video before it chooses, sound effects are placed only on
  real moments in the picture, and speakers are labelled. See [Derush edit](../recipes/derush-edit.md).
- **An Events lane in the editor.** [Events lane](../editor/events-lane.md) shows what happens in your video
  on the timeline, lets you snap to those moments and act on one with a single click.

The 0.3.0-alpha guide was captured before several pages were added. This version includes them:

  [Layer one video over another](../editor/layer-videos.md) and

- **Apps and recipes.** [App fields](../workflows/app-inputs.md), [Share a recipe](../recipes/share-a-recipe.md)

- **The assistant.** [Post text for a finished video](../assistant/post-text.md).

## What is not in it

- **The timeline editor is not final.** It is still an **Early preview** and is labelled as one on every
  editor screen. Expect tools to change.
- **Italian is not complete everywhere.** A page that is not translated yet is shown in English.

## Where it runs

ReelBolt 0.3.1-alpha runs on the hosted service at reelbolt.ai.

## Upgrade notes

There is nothing to migrate. To read the guide as it was for earlier alpha releases, choose
**0.3.0-alpha**, **0.2.0-alpha** or **0.1.0-alpha** in the version menu in the documentation header.
