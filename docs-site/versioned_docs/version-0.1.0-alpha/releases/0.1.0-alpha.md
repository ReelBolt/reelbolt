# ReelBolt 0.1.0-alpha

**Released** 19 October 2026 · **tag** `v0.1.0-alpha` · **commit** `3cffd3e9ae3d`

This is the first release of ReelBolt. It is an **alpha**: early access, no service-level guarantee, and
features may change. The rest of this guide describes what the release can do; this page records what changed
to produce it.

## What is in it

- **Prompted region effects follow the whole object.** When you ask ReelBolt to blur or highlight something
  in footage ("blur the speedometer"), it now follows that object when the segmentation service renumbers it
  part-way through a clip, covers every instance a prompt matches, and refuses to publish an effect whose
  mask is empty for part of the clip instead of showing a silent gap. A run that used to look applied from
  the wrong moment now either applies correctly or reports the problem.
- **Storage limits hold across replicas.** Two servers handling deletions at the same moment can no longer
  let a workspace exceed its plan's storage quota. Deletions and picture copies are checked and recorded
  under one lock, so the limit is the limit.
- **Releases are recorded only when they are healthy.** A host records the release it is running only after
  the new version comes up and passes its health check. A failed deploy or rollback no longer leaves a
  record naming a release that never ran.
- **Dashboards ship with the product.** Six Grafana dashboards and their provisioning are part of the
  repository, so an operator can load them without a hand import.
- **The release gate is green.** The compose check that blocked the freeze is fixed, so the gate that
  proves the frozen commit is sound passes.

## What is not in it

- **The timeline editor ships switched off.** The editor rework was deliberately deferred from the alpha
  and is disabled in this release. The picture editor described in this guide is available.

## Where it runs

Both ReelBolt hosts run this commit, and the release check agrees on both. The site is served from the
control host over HTTPS with a Let's Encrypt certificate issued on 19 October 2026.

## Upgrade notes

There is nothing to migrate: this is the first release. If you are testing the alpha, read
[What is ReelBolt](../index.md) for the product as a whole and [Getting started](../getting-started.md) for
your first project.
