# Release notes

These pages describe what each ReelBolt release contains. The user guide itself can be read as it was at any
released version: use the version menu in the documentation header to switch between the current working
copy and a release.

- [ReelBolt 0.1.0-alpha](./0.1.0-alpha.md) — 19 October 2026. The first alpha release.

Each release page records the version, the date, the commit and the tag, what is in the release, what was
deliberately left out, where it runs, and anything a tester or operator has to do before using it.
