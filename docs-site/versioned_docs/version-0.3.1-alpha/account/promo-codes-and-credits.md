# Promo codes and credits

This page covers how to use a promo code to lower the price of a plan or a credit pack, how to redeem a code for free credits, what automatic offers look like, and how promo credits expire and get spent. Only the workspace **Owner** and members with the **Billing** role can use codes. For the wider picture of plans and credits, see [Plans and credits](./plans-and-credits.md).

## Verify your email before you use a code

Promo codes, free-credit codes and offers with no code work only once the email address on your account is verified. If it is not, ReelBolt asks you to verify it when you apply or redeem a code. A checkout without a code is at the regular price until then. To verify, select the link in the verification email ReelBolt sent when you signed up.

## Enter a promo code

1. On **Settings → Plan and billing**, type the code into **Have a promo code?** and select **Apply**. Capital letters do not matter.
2. ReelBolt checks the code against the plans and packs you can buy. Where the code applies, the card shows the discounted price from the payment provider, with the regular price struck through, and the page says which plans or packs the code covers.
3. Select **Choose** on a plan, or choose a pack under **Buy credits**. The checkout opens with the discount already applied.

To try a different code, select **Remove code** and apply the new one.

## How long a plan discount lasts

A plan discount can cover the first payment only, a set number of months, or every payment. The price on the card is your first payment with the discount. The checkout shows what later payments cost.

## Offers with no code

When ReelBolt runs an offer that needs no code, the plans and packs it covers show a badge with the offer's name and the discounted price. The discount applies at checkout on its own.

A credit pack can also show **bonus credits**: extra credits added on top of the pack when you buy it. Bonus credits are promo credits and expire twelve months after the purchase.

## Hold an offer during checkout

When you open a checkout with an offer, ReelBolt holds that offer for an hour, so that other buyers cannot claim its last use while you pay. Opening a new checkout with the same offer replaces the earlier hold.

## When a code is refused

ReelBolt says "That code isn't valid." for any code that does not apply. The usual reasons are:

- the code is mistyped;
- the offer has ended, is paused, or has been fully claimed;
- the code was already used in another workspace;
- the code is for something else, such as a pack code entered for a plan.

After too many wrong codes in an hour, or too many checkouts with an offer in an hour, ReelBolt asks you to wait and try again later.

## Redeem a free-credit code

Some codes give the workspace free credits instead of a discount. You redeem them on **Settings → Plan and billing**, in **Redeem a code**. Only the workspace Owner and members with the Billing role can redeem one.

1. Type the code into **Code** and select **Redeem**.
2. ReelBolt adds the credits to the workspace balance and shows how many were added and the date they expire.

A workspace can usually redeem each code once, and so can each person. A code you redeemed in one workspace cannot be redeemed again in another. If the code has already been used that way, ReelBolt says so and adds nothing. A code whose uses have all been claimed reads as "That code isn't valid."

## Promo credits and when they expire

Promo credits are free credits from a code, from a pack bonus, or from a ReelBolt administrator. They are spent from the same balance as every other credit.

- **They expire.** Each batch has its own expiry date, shown when you receive it. Credits not used by that date are removed.
- **They are spent before bought credits.** Trial, plan and promo credits are spent before the credit packs you bought, and among them the credits that expire soonest go first.
- **They have no cash value.** Promo credits cannot be exchanged for money and cannot be moved to another workspace.
- **A refund takes the bonus back.** If a credit pack is fully refunded, its bonus credits are removed along with the pack's own credits.

To see them, open **Settings → Plan and billing** and look under **Credits by expiry**. Each batch shows how many credits are left, where they came from (**Free trial credits**, **Plan credits**, **Purchased credits** or **Promo credits**) and when it expires.
