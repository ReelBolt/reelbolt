# Sound library credits

Recorded and designed sounds in the built-in library come from the following packs. All are released by their
author under **Creative Commons Zero 1.0 (CC0 1.0)**, a public-domain dedication
(<https://creativecommons.org/publicdomain/zero/1.0/>). Credit is not required; it is given here anyway.

| Pack | Author | Licence | Source | Files used |
|---|---|---|---|---|
| Digital Audio | Kenney (kenney.nl) | CC0 1.0 | <https://kenney.nl/assets/digital-audio> | 15 |
| Impact Sounds (1.0) | Kenney (kenney.nl) | CC0 1.0 | <https://kenney.nl/assets/impact-sounds> | 19 |
| Interface Sounds (1.0) | Kenney (kenney.nl) | CC0 1.0 | <https://kenney.nl/assets/interface-sounds> | 38 |
| Sci-Fi Sounds (1.0) | Kenney (kenney.nl) | CC0 1.0 | <https://kenney.nl/assets/sci-fi-sounds> | 15 |
| UI SFX Set | Kenney (kenney.nl) | CC0 1.0 | <https://kenney.nl/assets/ui-audio> | 9 |

Each used file is trimmed, mixed down to mono, loudness-normalised and re-encoded as Ogg Vorbis; the manifest
(`inference/src/ReelBolt.Inference.Api/Services/SfxLibrary/sfx-library.manifest.json`) records, per file, the
original file name, the source page, the licence name, version and URL, the quoted proof text, the retrieval date
and the SHA-256 of the stored bytes. The remaining effects are first-party synthesized (licence `ReelBolt-original`).
