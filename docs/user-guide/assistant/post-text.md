# Post text for a finished video

When a video is finished you can ask the assistant (in the app, or Claude through the ReelBolt connector) to write the text you post with it: a title where the platform has one, the body, and the hashtags. Name the platforms you want, for example "write the post text for TikTok and LinkedIn". You get one version per platform, cut to the length each platform allows.

The assistant only shows you the text. It does not save it and it does not post it for you. To keep a version, save it from the video's post-text panel in the app.

## What it writes from

The assistant writes from what ReelBolt already holds about the video: the project details, the brief, the script and the narration. It does **not** look at the video or listen to it. If you want the text to be written from what is in the video, open the video in the app and use the **Write post text** dialog: that is where "also read the video" lives, and it shows the price before anything is read.

One optional extra, only when you ask for it in your message:

- **Hashtags from a web search.** The assistant looks up hashtags on the web for this kind of video and picks from what it finds, with the pages they came from.

## What leaves ReelBolt

A plain request sends nothing beyond your workspace's chat model. Asking for hashtags from the web also sends the project name and the about text as a search query to your workspace's web search provider. No video, frame or script text is sent. Which provider that is depends on how your workspace is set up.

## Hashtags are suggestions

Hashtags come from the model, or from a web search when you ask. They are suggestions, not measured trends. ReelBolt does not say that a hashtag is trending, and you should check the platform before you rely on one.

## Cost and limits

Every request spends credits, a small amount; the reply says how much. If your credits are too low, nothing is written and nothing is charged. A request that fails is charged only for what it used. Each person can ask for a limited number of texts per project per hour.
