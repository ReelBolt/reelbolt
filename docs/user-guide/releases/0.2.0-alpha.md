# ReelBolt 0.2.0-alpha

**Released** 27 October 2026 · **commit** `a991d80b2bf2`

This is the second alpha cut of the user guide, published for the first invited testers. It is still an
**alpha**: early access, no service-level guarantee, and features may change. This page records what the
guide now describes that [0.1.0-alpha](./0.1.0-alpha.md) did not; the rest of the guide describes what
ReelBolt can do today.

## What is in it

- **The timeline editor is documented, as an Early preview.** [The timeline editor](../editor/index.md)
  covers opening a timeline, playing it, cutting and moving clips, markers and undo. Companion pages cover
  [saving and recovering](../editor/saving-and-recovering.md) your work,
  [exporting your film](../editor/export-your-film.md) and
  [sharing a film for review](../editor/share-for-review.md). Every editor page carries an **Early preview**
  label: your work is saved, but some tools may change.
- **The ReelBolt Runner has its own guide.** [ReelBolt Runner](../runner/index.md) explains what the
  desktop app is and what your computer needs, then walks through installing it on
  [Linux](../runner/install-linux.md) or [Windows](../runner/install-windows.md),
  [verifying the download](../runner/verify-download.md), [pairing](../runner/pairing.md) it with your
  workspace, [updates](../runner/updates.md), [privacy](../runner/privacy.md),
  [troubleshooting](../runner/troubleshooting.md) and [uninstalling](../runner/uninstall.md).
- **Ask for changes to a finished video.** [Request changes](../workflows/request-changes.md) describes
  changing only the parts you name in an animated video ReelBolt already made, with every version kept.
- **Choose a recipe, set the brief.** [Choose a recipe](../recipes/choose-a-recipe.md) matches what you
  want to make to the recipe that makes it, and [Run settings](../recipes/run-settings.md) explains each
  setting on a recipe's run page. New recipes: [add subtitles](../recipes/subtitles.md),
  [a promo in your brand](../recipes/promo-in-your-brand.md) and
  [a promo with AI backgrounds](../recipes/promo-with-ai-backgrounds.md).
- **Web search for agents.** [Web search](../workflows/web-search.md) says what it does, how an admin turns
  it on, what it costs and how to treat the results.
- **Billing wording names your payment provider.** The plan and billing pages no longer name one specific
  provider; buttons and messages such as **Manage in …** use the name of the provider your workspace pays
  through.
- **A guide to running your own ReelBolt.** [Self-hosting ReelBolt](../self-hosting.md) covers
  requirements, the secrets you must set, first sign-in and hardening.
- **A clearer layout.** Pages about connecting files now sit under Projects, and the assistant and its
  Claude Code connection under Assistant. The old addresses of pages that moved still lead to them.

## What is not in it

- **The timeline editor is not final.** It is available as an Early preview and is labelled as one on every
  page. Expect tools to change before the label is lifted.

## Where it runs

This guide describes the build that serves the first invited testers (commit `a991d80b2bf2`), with its
version label moved to **0.2.0-alpha**: the product, the dashboard and this documentation show the same
version. The previous guide, 0.1.0-alpha, stays published and can be opened from the version menu in the documentation header.

## Upgrade notes

There is nothing to migrate. If you read the guide before today, the wording that changed most is in the
editor pages (the editor is an Early preview) and the plan and billing pages (the payment provider is named
by the buttons, not by the text). To read the guide as it was at the first alpha, choose **0.1.0-alpha**
in the version menu.
