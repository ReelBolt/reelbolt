# Release notes

These pages describe what each ReelBolt release contains. The user guide itself can be read as it was at any
released version: use the version menu in the documentation header to switch between the current working
copy and a release.

- [ReelBolt 0.4.0-alpha](./0.4.0-alpha.md) — The first open-source release, annual plans and phone fixes.
- [ReelBolt 0.3.1-alpha](./0.3.1-alpha.md) — 10 November 2026. A point release: the public API and better footage edits.
- [ReelBolt 0.3.0-alpha](./0.3.0-alpha.md) — 10 November 2026. The third alpha release.
- [ReelBolt 0.2.0-alpha](./0.2.0-alpha.md) — 27 October 2026. The second alpha cut, for the first invited testers.
- [ReelBolt 0.1.0-alpha](./0.1.0-alpha.md) — 19 October 2026. The first alpha release.

Each release page records the version, the date, the commit and, where there is one, the tag, what is in the release, what was
deliberately left out, where it runs, and anything a tester or operator has to do before using it.
