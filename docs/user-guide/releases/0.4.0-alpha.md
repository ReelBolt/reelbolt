# ReelBolt 0.4.0-alpha

**Released** &lt;date to fill at the cut&gt; · **tag** `v0.4.0-alpha`

This release makes ReelBolt open source for the first time. It is still an **alpha**: early access, no
service-level guarantee, and features may change. This page records what you can do now that you could
not do in [0.3.1-alpha](./0.3.1-alpha.md). Security fixes are included in this release.

## ReelBolt is now open source

The source code is public at [github.com/ReelBolt/reelbolt](https://github.com/ReelBolt/reelbolt).

- **Licence.** ReelBolt's own code is free software under the GNU Affero General Public License, version 3
  (AGPL-3.0). A separate **commercial licence** is available if the AGPL does not fit your use.
- **Run it yourself.** The [self-hosting guide](../self-hosting.md) shows how to start your own copy and
  what it needs.
- **Remotion.** ReelBolt renders its videos with Remotion, which has its own licence and is not covered by
  ReelBolt's. Remotion's free tier covers up to three people. An organisation of more than three people
  needs a Remotion Company License. When you self-host, you are the licensee for your installation; the
  [self-hosting guide](../self-hosting.md) has the details.

## What is in it

- **Plans, annual billing and clearer plan cards.** You can pay for a plan monthly or yearly, using the
  Monthly/Annual switch in the dashboard and on the pricing page. The plan cards now show the storage and
  the features each plan includes. Choose a plan before you sign in and ReelBolt opens that plan's checkout
  after your first sign-in. For prices, see the pricing page on reelbolt.ai; this guide does not repeat them.
  See also [Plans and credits](../account/plans-and-credits.md) and
  [Managing your plan](../account/managing-your-plan.md).
- **Better on a phone.** The project tabs no longer overlap, the project overview tiles wrap cleanly, and
  the resolution selector on the run page no longer runs off the screen. The phone top bar and run page
  were also fixed.
- **A simpler start.** A guided first film with a sample clip, a one-click **Run it** or
  **Review and run** after an upload, and plainer words in the dashboard: *app*, *video* and *run*.
- **Pictures in your workflows.** A new image step creates pictures from text or makes several edited
  variations, with a size you choose. Pictures load faster, and a run's pictures appear in a gallery
  instead of a broken video player. See [Step types](../workflows/step-types.md).
- **Publish your videos.** Post a finished video to YouTube Shorts or LinkedIn, now or later, and see how
  each post performs. See [Publishing, scheduling and performance](../projects/publishing.md).
- **Sound effects.** Search the sound library and add effects to a project, in the editor and through the
  assistant. See [Sound effects](../editor/sound-effects.md).
- **Simple and Full editor.** The editor has a Simple layout beside the Full one, over the same timeline.
  See [Simple and Full](../editor/simple-and-full.md). The editor also has a clearer Deliver page and
  Colour page, and live preview on every device.
- **Avatars.** A shared avatar library for your workspace, avatars of objects, and avatar clips. See
  [Avatar library](../projects/avatar-library.md) and [Avatar clips](../editor/avatar-clips.md).
- **Set your own video spend limit.** The per-plan daily video caps are gone. You choose a daily video
  spend limit yourself. See [Daily video limit](../account/daily-video-limit.md).
- **Choose how many b-roll clips.** An app can let you set the number of b-roll clips and a spend cap.
  See [App fields](../workflows/app-inputs.md).
- **Better films.** Cuts that land on the beat, even loudness, no black opening frames, and checks for
  low-contrast text and frozen frames before a film is finished.
- **Clearer failures.** A failed screen insert now says why, what it cost, and what to try next.
- **The public API.** Apps now describe their inputs so your code can discover them, new keys have a
  default daily cap, and Trial keys are read-only. See [Apps](../api/apps.md).
- **Documentation.** Offline search in English and Italian, a home page organised by goal, and Italian
  pages kept up to date.

## Security and reliability

Next.js and the web server were upgraded to patched versions, and several fixes make long renders and
analysis jobs more dependable.

## Still an alpha

- **The timeline editor is not final.** It is still an **Early preview** and is labelled as one on every
  editor screen. Expect tools to change.
- **Italian is not complete everywhere.** A page that is not translated yet is shown in English.
- **No service-level guarantee.** Features can change between releases.

## Where it runs

ReelBolt 0.4.0-alpha runs on the hosted service at reelbolt.ai, and you can run it yourself from the
public repository.

## Upgrading

Nothing to do on the hosted service. If you run your own copy, follow the
[self-hosting guide](../self-hosting.md). To read the guide as it was for earlier alpha releases, choose
**0.3.1-alpha**, **0.3.0-alpha**, **0.2.0-alpha** or **0.1.0-alpha** in the version menu in the
documentation header.
