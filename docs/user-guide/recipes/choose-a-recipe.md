# Choose an app

:::note
The footage apps below are now three apps: [Edit my video](edit-my-video.md), [Languages](languages.md) and [Effects on a clip](effects-on-a-clip.md). The old names still open them with the matching field set.
:::

An app is a ready-made way to make a video: you pick it from **Apps** in a project, fill in a few
settings, and press **Run**. Each page below says what to set before you run it, what it
costs in words, what you get and what to do when something goes wrong. The exact price of a run
shows on the run page before you start it.

Two words you will meet: a **derush** is the first cut of raw footage, with the dead air and retakes removed. **B-roll** is extra footage shown over the main shot.

Not sure? Ask the [assistant](../basics/assistant-basics.md). It tells you which app is closest, or that none fits.

## What ReelBolt cannot do yet

- **Long talking avatars.** Where [avatars](../projects/avatars.md) are enabled, **Talking avatar (budget)** makes a
  project avatar say a short script (5 to 15 seconds) and **Spokesperson clip** shows an avatar without exact words;
  you pick the person in the **Avatar** field of the app page. Where app fields are enabled, the two are one app,
  **Avatar clip**, with a **Lite mode (cheaper)** switch for the short script (see [Run settings](run-settings.md#recipe-fields)).
  [Avatar explainer from a topic](avatar-explainer.md) makes a talking clip from a topic, but it is also about 15 seconds
  at most. There is no app for a longer presenter video.
  For a narrated video, use [Footage edit with narration and captions](voiceover.md#recipe-footage-edit-with-narration-and-captions)
  on real footage, or a promo with a [voiceover](voiceover.md). To ask for it anyway, tell the [assistant](../basics/assistant-basics.md).
- **Image carousels.** There is no app that makes a set of still slides for a social carousel.
- **Reformatting a finished video.** There is no app that takes a finished video and re-cuts it
  to another shape, such as a landscape film into a vertical one. You choose the shape (**Shape**
  in [Run settings](run-settings.md)) before an app makes a new video; you cannot change it after.

If your goal is not in the tables, describe it to the [assistant](../basics/assistant-basics.md). It tells you which app is
closest, or that none fits, instead of starting a run that cannot give you what you asked for. Ask it
about carousels or reformatting too: it can tell you what is planned and what is not.

## Before you press Run

Every app shows a short readiness line above **Run**. A missing clip, code archive, music
track, profile or provider is named there, with a link that fixes it. See
[Run settings](run-settings.md) for what each setting changes.
