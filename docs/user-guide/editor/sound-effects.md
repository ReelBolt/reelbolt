# Sound effects

ReelBolt comes with a library of short sound effects: whooshes, pops, clicks, dings, hits and more. They are free to use in any project. Using them costs no credits and does not use up your storage.

You find them in the **Sound effects** tab of the media pool in the editor. On a phone, open the add-media sheet and choose **Sound effects**.

## Find a sound

- Type in **Search sound effects** to look by name or tag, for example "whoosh" or "transition".
- Pick a category to see only that kind of sound.
- Use **Maximum length** to see only short sounds, with the choices 1, 3 or 10 seconds.

## Hear it

Tap or click a sound to play it, and tap or click it again to stop. A sound never plays just because the pointer is over it.

## Add it to your project

Press **Add** next to a sound. A copy is added to your project's media, and the row then says **Added**. Adding the same sound again does not make a second copy.

Once it is in your project you use it like any other audio file. In the editor, adding a sound also places it on an audio track at the playhead.

## Add a starter set

If you are not sure where to begin, press **Add starter set**. It adds about 24 varied sounds at once, a few from each category, so a new project has something to work with. Sounds already in the project are skipped.

## Use them in a workflow

A sound you added is an ordinary audio file in the project. A recipe such as **Footage edit with sound effects** offers the audio files in your project to its sound designer, so the sounds you added can land on your cuts. You can also ask the assistant to find a sound and add it. It asks for your approval before it adds anything.

## Limits

- A project can hold a limited number of library sounds. If you reach the limit, the editor says so, and you can remove some from the media pool to add more.
- If you press **Add** many times in a short while, the editor asks you to wait a minute.
- A sound the library no longer offers cannot be added. The editor says that it is no longer in the library.

The editor is part of the **Early preview**, so some tools may change.
