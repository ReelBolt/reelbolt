# Ask for changes

You will ask for a change to a finished video. Only the parts you name are changed, and your current video is kept.

## Request a change

1. Open the page of the finished run.
2. In the **Change this video** card, under **The video itself**, write what should change. Be specific about what and where. "Make the numbers in the stats section bigger" works better than "make it better".
3. Optional: under **Only these scenes**, pick the scenes the change is about.
4. Optional: under **Start from**, pick an earlier version.
5. Check the credits shown on the card, then confirm.

![The Change this video card on a finished run with a change typed in](./img/ask-for-changes-01.webp)

You should see a new run open. Follow it the same way as before. When it finishes, the new version appears on the **Videos** tab (where finished videos are listed) next to the old one.

:::tip If something looks different
- No **The video itself** section? It shows on finished runs of animated videos only; the rest of the card still lets you change steps. For other videos, run the app again with a new brief, or use the [editor](./editor-basics.md).
- Part of your animation sits inside a longer edit? The card lists the later steps that run again and lets you choose what happens to the edit.
:::

Need to change several things at once, like the narration and the graphics? It is the same card: add each change to the list, including the video itself, and confirm once; see [Changing several things at once](../workflows/request-changes.md#changing-several-things-at-once).
