# Impostazioni di esecuzione (il brief) {#run-settings-the-brief}

Le impostazioni nella pagina di esecuzione di una ricetta formano insieme il **brief** di quell'esecuzione. La pagina mostra
solo le impostazioni che la ricetta usa davvero, quindi una ricetta senza voce narrante non ha
l'impostazione della voce narrante. Lascia vuota un'impostazione per dire che non hai preferenze.

## Lingua {#language}

La lingua di tutto ciò che lo spettatore legge o sente: testo a schermo, sottotitoli e voce narrante.
Scegli una lingua, oppure lascia l'impostazione su automatico. Una ricetta che monta girato ha anche **Lingua parlata**,
cioè la lingua in cui si parla nei tuoi clip; aiuta a trovare le parole al loro interno.

## Durata {#length}

Un obiettivo in secondi, tra 5 e 600. È un obiettivo, non una garanzia: il risultato si avvicina a quel valore
e un breve clip di girato non può essere allungato oltre quello che hai filmato.

## Formato {#shape}

L'inquadratura del video: verticale (9:16), quadrato (1:1), orizzontale (16:9) o ritratto (4:5). Sceglilo
prima di avviare. Un video finito non può essere cambiato in un altro formato in seguito.

## Voce narrante {#narration}

Se il video ha una voce narrante e con quale voce. Scegli **Con voce narrante** e una voce per cui hai
il consenso. Questa impostazione compare solo nelle ricette che possono parlare. Vedi [Aggiungi una voce narrante](voiceover.md).

## Stile {#style}

Lo stile di montaggio e il tono: ritmo, tagli, sottotitoli e atmosfera. Una ricetta può suggerire uno stile, mostrato
come chip; puoi cambiarlo.

## Design {#design}

In quale brand è costruito il video. Usa il design approvato del tuo progetto (l'impostazione predefinita), oppure scegli
nessuno per avviare senza i colori e i caratteri del brand. Vedi [Design system](../design-system.md).

## File {#files}

I file su cui lavora una ricetta: i tuoi clip, la musica, le immagini o un archivio di codice. Scegli i file tra quelli
del progetto. Una ricetta che richiede un file che non hai caricato lo segnala sopra **Avvia**.

## Note {#notes}

Testo libero per tutto ciò che le altre impostazioni non coprono: a chi è destinato il video, cosa deve
mostrare, cosa tenere. Se le note sono in contrasto con un'impostazione, vince l'impostazione.

## Campi della ricetta {#recipe-fields}

Dove il tuo spazio di lavoro li ha, alcune ricette chiedono anche qualche campo proprio, ognuno con un esempio nella
casella. Quelli che si cambiano più spesso sono visibili; gli altri stanno in **Altre opzioni**, chiusi finché non li
apri. Un campo lasciato vuoto mantiene l'impostazione della ricetta.

| Ricetta | Campi | In Altre opzioni |
|---|---|---|
| Video promozionale dal tuo codice, leggero e nel tuo brand | **Invito all'azione** (l'ultima cosa che il video chiede di fare) | **Modello per il testo**, **Modello che costruisce il video** |
| Promo con sfondi IA | **Invito all'azione**, **Aspetto degli sfondi** (i colori e l'atmosfera degli sfondi) | **Modello IA per gli sfondi**, **Modello per il testo**, **Modello che costruisce il video** |
| Spotlight narrato, trailer di lancio, storia narrata | **Per chi è**; la storia narrata ha anche **Sottotitoli** | |
| Montaggio dei momenti migliori (anche con stanze, grafica, colore o effetti sonori), reel di testimonianze | **Sottotitoli** (spenti di base: le parole dette nelle tue clip, che vengono trascritte per questo) | **Dissolvenza finale** (accesa di base) |
| Montaggio con voce narrante e sottotitoli, doppiaggio | **Sottotitoli** (attivi di base) | **Dissolvenza finale** |
| Montaggio con musica di sottofondo | | **Volume della musica** (vuoto lascia scegliere al montatore), **Dissolvenza finale** |
| Montaggio con inquadrature extra IA | | **Modello video**, **Dissolvenza finale** |
| Dailies | | **Take per inquadratura** (da 1 a 3), **Modello video**, **Dissolvenza finale** |
| Sfoca un oggetto | **Cosa nascondere** (l'oggetto, a parole semplici), **Come nasconderlo** (sfocatura o pixelatura) | |
| Sottotitoli, sottotitoli in un'altra lingua | **Stile dei sottotitoli**: semplice, parola per parola o una parola grande | |
| Clip con avatar | **Avatar**, **Modalità leggera (più economica)**, **Cosa fa** o **Cosa dice**, **Formato**, **Durata** | **Modello video**, oppure in modalità leggera **Modello di sincronizzazione labiale** e **Modello per l'immagine** |

**Dissolvenza finale** sfuma immagine e audio alla fine, esattamente come queste ricette hanno sempre fatto; spegnila per
un film che si ferma sull'ultimo fotogramma. Anche la storia narrata la ha in **Altre opzioni**.

Un campo modello elenca i modelli che puoi scegliere, prima quello consigliato, con il prezzo a parole rispetto a
quello (per esempio "Circa 2× il prezzo"). Cambiare un modello, una durata, un formato o un interruttore aggiorna il
prezzo mostrato sopra **Avvia**; cambiare un testo no.
