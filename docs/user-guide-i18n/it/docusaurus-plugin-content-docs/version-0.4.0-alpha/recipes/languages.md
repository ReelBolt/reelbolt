# Lingue {#languages}

**Obiettivo:** far funzionare un video in più di una lingua. Il risultato è un nuovo MP4 e i sottotitoli arrivano anche come file SRT
e VTT.

Questa app sostituisce le vecchie ricette di sottotitoli, sottotitoli tradotti e doppiaggio. I vecchi nomi la aprono con
i campi corrispondenti già impostati.

## Prima di avviarla {#before-you-run-it}

- **Il tuo video** caricato nel progetto, con del parlato.
- Un provider di trascrizione. Una traduzione richiede anche un provider di chat; un doppiaggio anche un provider di voce.

## I campi {#the-fields}

| Campo | Che cosa fa |
|---|---|
| **Il tuo video** | Il video su cui lavorare. |
| **Sottotitoli** | Spenti o impressi nell'immagine. I file SRT e VTT arrivano con loro. |
| **Traduci i sottotitoli** | Attivalo per tradurli nella lingua di destinazione, impressi con il tempo originale. |
| **Lingua di destinazione** | La lingua della traduzione o del doppiaggio. |
| **Doppiaggio** | Spento, o una traduzione parlata che sostituisce le voci. Le labbra non sono risincronizzate. |

In **Altre opzioni**: la voce del doppiaggio, la lingua parlata e le note.

## Che cosa paghi {#what-you-pay-for}

La trascrizione è sempre usata. La traduzione e la voce del doppiaggio sono usate solo se le attivi, e la stima
mostra esattamente questo.
