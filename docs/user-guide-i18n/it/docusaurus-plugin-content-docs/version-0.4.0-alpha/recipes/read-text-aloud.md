# Fai leggere ad alta voce il tuo testo {#read-your-text-aloud}

**Obiettivo:** ottenere un file audio con una voce che legge il tuo testo.

## Ricetta: Read my text aloud {#recipe-read-my-text-aloud}

**Input.** **Text to read**, una **Voice** e una **Language**. In **More options** puoi scegliere il modello della voce. Serve un fornitore di voce nel tuo spazio di lavoro. Il testo viene letto così com'è scritto: non viene tradotto né riscritto.

**Quanto costa.** Usa crediti e una voce. Il prezzo appare nella pagina di esecuzione prima che tu avvii.

**Cosa ottieni.** Un file audio nel progetto.

**Se fallisce.**

- L'esecuzione si ferma chiedendo una voce: aggiungi un fornitore di voce al tuo spazio di lavoro.
- Un paragrafo lungo viene rifiutato: dividilo in paragrafi più brevi.
- La lettura è nella lingua sbagliata: imposta **Language** sulla lingua del testo. Per una traduzione, scrivi tu il testo tradotto.

**Permesso di inviare media.** Al fornitore di voce va solo il tuo testo. Nessuna immagine o video viene inviato.
