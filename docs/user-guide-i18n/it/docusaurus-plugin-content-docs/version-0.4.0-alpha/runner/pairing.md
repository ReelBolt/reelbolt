# Collegare il Runner {#pair-the-runner}

Il collegamento parte dal tuo computer e si completa in ReelBolt.

1. Avvia il Runner. Su Windows, apri **ReelBolt Runner** dal menu Start. Su Linux, avvia l'app oppure esegui `reelbolt-runner pair`.
2. Il Runner mostra un breve codice di otto caratteri, come `7HQD-4M2R`, e apre una pagina di ReelBolt nel browser. Se non si apre nessun browser, apri l'indirizzo stampato dal Runner.
3. Accedi a ReelBolt se richiesto. Nella pagina **Collega un runner**, controlla che il codice corrisponda carattere per carattere a quello sul tuo computer.
4. Scegli lo spazio di lavoro a cui collegare il computer. Puoi scegliere il tuo spazio di lavoro Personale o qualsiasi spazio di lavoro in cui sei Proprietario o Amministratore.
5. Clicca **Approva questo dispositivo**. Clicca **Rifiuta** se non sei stato tu ad avviare l'operazione.
6. Torna al Runner. Mostra che è collegato. Il computer ora compare nello spazio di lavoro in **Runner**.

Il codice dura poco. Se scade, chiedi al Runner un codice nuovo. Ogni Proprietario dello spazio di lavoro riceve un'email quando un dispositivo viene approvato.

Come lo spazio di lavoro decide quando usare il tuo computer, e come rimuoverlo, è spiegato nella pagina [Runner desktop](../account/desktop-runner.md).
