# Note di rilascio {#release-notes}

Queste pagine descrivono cosa contiene ogni rilascio di ReelBolt. La guida utente si può leggere così com'era in
qualsiasi versione rilasciata: usa il menu delle versioni nell'intestazione della documentazione per passare
dalla copia di lavoro attuale a un rilascio.

- [ReelBolt 0.3.1-alpha](./0.3.1-alpha.md) — 10 novembre 2026. Un rilascio di aggiornamento: l'API pubblica e montaggi dei filmati migliori.
- [ReelBolt 0.3.0-alpha](./0.3.0-alpha.md) — 10 novembre 2026. Il terzo rilascio alpha.
- [ReelBolt 0.2.0-alpha](./0.2.0-alpha.md) — 27 ottobre 2026. Il secondo taglio alpha, per i primi tester invitati.
- [ReelBolt 0.1.0-alpha](./0.1.0-alpha.md) — 19 ottobre 2026. Il primo rilascio alpha.

Ogni pagina di rilascio riporta la versione, la data, il commit e, dove c'è, il tag, cosa contiene il rilascio, cosa è
stato lasciato fuori di proposito, dove gira e tutto ciò che un tester o un operatore deve fare prima di usarlo.
