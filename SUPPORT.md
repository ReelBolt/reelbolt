# Getting support

- **Using ReelBolt:** read the [user guide](docs/user-guide/index.md) and [troubleshooting](docs/user-guide/troubleshooting.md).
- **Self-hosting questions and bugs:** open an [issue](https://github.com/ReelBolt/reelbolt/issues/new/choose) with your steps, the output of `docker compose logs <service>` and your version.
- **Source code of GPL components in the container images or the desktop runner:** write to **legal@reelbolt.ai** and say which image or runner version you have. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) says where each component's source is.
- **Feature ideas:** open a feature request issue.
- **Hosted service (reelbolt.ai):** use the contact page on the site.
- **Security vulnerabilities:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).

Self-hosted support is community-based and best effort.
