# Public Alpha

## Overview

Public Alpha is a warm, high-contrast system for product marketing. It pairs a
dark canvas with a single saturated accent, and it never decorates for its own sake.

## Do's and Don'ts

### Do's

- Lead with the headline.
- Keep one accent per screen.
- Prefer generous spacing.

### Don'ts

- Don't stack two accents.
- Don't use pure black text.

## Tone

- Confident
- Plain-spoken
- Warm
