# Provenance: f2-face replay

`response.json` is a **vendor output replayed offline** (data, never code): a `fal-ai/sam-3-1/video-rle`
response for a "person" prompt on a short clip. `meta.json` holds the request inputs.

The clip behind it was an **AI-generated person, not a real person**, made by the ReelBolt team (generated with MiniMax,
model as recorded: `MiniMax-H3-Max`, per the project owner). The clip itself is not in this repository; only the response is.
